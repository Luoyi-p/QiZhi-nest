# 第一版验证记录

日期：2026-09-15。范围：本地个人学习与数字工作台，不包含公网部署。

## 验证结果

- `npm run build`：Vue TypeScript 检查及 Vite 生产构建通过。
- `python -m pytest -q`：17 项 API 行为测试通过。依赖 Starlette 有一条 AnyIO 弃用提示，不影响本轮测试结果。
- 浏览器：工作台加载、笔记编辑保存、学习里程碑更新、刷新保留进度、手机导航进入资料库均已实际操作。
- 布局：检查过 1440px 桌面与 390px 手机视口；检查时文档宽度未超过视口宽度。
- 数据：测试使用独立临时数据库；浏览器检查使用明确标记的示例，切换过的里程碑已恢复。

## Standards

按 `CONTRIBUTING.md` 人工复核了输入校验、参数化 SQL、事务、错误反馈、重复提交保护和私有数据忽略规则。发现手机侧栏仅平移隐藏，会让不可见链接留在键盘导航中；已补充关闭时的可见性控制和菜单展开状态。

未完成两名独立审查代理的报告：它们均因额度限制退出。这里记录的是主代理复核，不冒充独立审查结果。

## Spec

按 `docs/SPEC.md` 检查了路线、内容关联、学习记录、归档、导入导出及本地启动路径。修正了三个细节：

1. 技术笔记不再因字符串清理丢失正文首尾的缩进与换行；补充备份往返测试。
2. 最近内容与时间线按实际时间戳排序，避免时区偏移不同的记录被按字符串错误排序。
3. 时间线列表键同时包含内容类型与 ID，避免备份中跨集合相同 ID 冲突。

统计：Standards 1 项、Spec 3 项，均已修复；未发现需要阻止本地第一版交付的剩余问题。未执行公网鉴权测试、长时间压力测试或全量浏览器自动化测试，项目也未承诺这些能力。
