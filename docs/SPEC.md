# 栖知 Nest · 第一版产品范围

用户要求：个人技术学习的入口，与个人数字化合并；使用 Vue 和 Python，适合上传 GitHub，避免大众化项目。

## 产品定义

单人、本地优先的数字工作台。以学习主题为线索，将资料、笔记、实践项目、学习记录连接在一起。应用名称与初始示例属于第一版可替换设计。

## 第一版验收范围

1. Vue 3 + TypeScript 前端，Python FastAPI 后端，SQLite 保存数据；重启后内容不丢失。
2. 工作台展示下一步学习、常用入口、真实记录统计、学习活跃图与最近笔记。
3. 学习路线可以创建、编辑，定义和勾选里程碑；进度由完成数计算。
4. 资料、笔记、项目均可创建和编辑，支持标签、状态、置顶和关联路线。
5. 支持标题、正文、标签搜索；资料页面支持状态、置顶和路线筛选。
6. 可以记录学习主题、分钟数和关联路线，时间线显示学习及内容创建记录。
7. 可以归档、恢复路线与内容；归档不删除关联内容。
8. JSON 完整导出、合并导入；同 ID 保持本地内容，重复导入不重复新增，无效备份不得部分导入。
9. 首次启动的演示数据有明确标记，可以关闭显示；隐藏示例时统计同时排除示例。
10. 桌面与手机可用，表单有标签、校验、忙碌状态、错误反馈，弹窗支持键盘焦点与 Escape 关闭。
11. 提供启动说明、依赖锁文件、自动化测试和 GitHub CI；数据库、虚拟环境、私人备份不提交到仓库。

## 当前边界

不包含多用户登录、公开网络部署、跨设备自动同步、附件上传、外部账号接入或 AI 服务。笔记为纯文本编辑；不会把用户输入直接渲染成 HTML。公开源码不等于公开个人数据。
