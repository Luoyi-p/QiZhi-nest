# 界面约定

界面采用浅色主题，包含工作台、学习路线、资料库、笔记、项目、时间线和数据设置七个入口。

## 颜色与布局

- 黑白灰为基础，蓝色表示主要操作、当前导航与进度。
- 主文字 `#18181B`，背景 `#FAFAFA`，卡片 `#FFFFFF`，强调色 `#2563EB`，次级文字 `#626774`。
- 浅灰侧栏区分导航，深蓝区块放置快捷记录入口，统计区域用分隔线分组。
- 路线分类同时使用文字、图标和颜色，避免只靠颜色区分。
- 使用系统字体和 Lucide 图标，不加载远程字体。
- 共用样式位于 `frontend/src/style.css`，间距以 4px、8px 为基础。

## 交互

- 窄屏使用导航抽屉和单列卡片，标题与标签允许换行。
- 手机表单输入字号至少 16px，编辑弹窗保留可滚动区域和底部操作按钮。
- 控件提供可见焦点；保留加载、错误、空状态及提交反馈。
- 导航支持跳转正文、页面切换后的焦点定位，以及抽屉内的 Tab 循环和 Escape 关闭。
- 表单使用原生 `dialog` 管理焦点，关闭后返回触发控件。
- 动画遵循 `prefers-reduced-motion`。
- 文案直接描述内容或操作；空状态给出下一步，避免重复宣传语。

## 检查范围

修改布局时检查 375、768、1024、1440px 宽度，关注横向溢出、长文本、导航和弹窗操作。键盘检查包括 Tab、Shift+Tab、Escape 和关闭后的焦点恢复。

当前只实现浅色主题。历史检查结果与本次自动化检查见 [验证记录](VERIFICATION.md)。

设计参考：[UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的 Minimalism / Swiss Style 建议。
